# Resume Maintenance

This folder keeps the CV separate from the homepage source.

- `HongningLiu-CV.md`: primary editable source.
- `HongningLiu-CV.html`: print-ready public CV. Open it in a browser and use Print -> Save as PDF.
- `private/`: local-only drafts or versions with phone/address details. This folder is ignored by Git.

Suggested workflow:

1. Update `HongningLiu-CV.md` first.
2. Mirror the same content into `HongningLiu-CV.html` when the printable version should change.
3. Keep sensitive contact details out of committed files unless you intentionally want them public.
